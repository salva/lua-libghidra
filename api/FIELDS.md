Source facts only, **not runtime acceptance or Lua call grammar**. See
[API](../docs/API.md) for call grammar, validation and effective bounds.
Included means reachable from an implemented native operation or the local
factory, not a populated producer or independently qualified runtime result.
Native-only models/enums have no supported Lua conversion claim. Defaults
do not imply optional positional arguments. UInt64 never uses floats.

model fields are retained (including full-tier/excluded models); the core
grammar and envelope-to-model mapping are in [API](../docs/API.md) and
[M3 core](../docs/M3-CORE.md#grammar-and-field-manifest) and
[M4 full](../docs/M4-FULL.md#call-grammar-and-dispatch-manifest). See
[SPEC](../docs/SPEC.md) for validation and effective downstream bounds.

fields refer to the corresponding model below. UInt64 never uses floats.
